# PlaylistMachine


Uma máquina de venda automática de playlists musicais, desenvolvida com uma interface moderna e futurista, inspirada em máquinas físicas de vending machine.

O projeto permite que os usuários explorem diferentes gêneros musicais, como MPB, Lo-Fi, música clássica, funk, gospel, punk, metal, rock e indie, cada um representado por uma capa e um código alfanumérico exclusivo.

### ✨ Funcionalidades
- Vitrine interativa com playlists organizadas por gênero musical.
- Sistema de seleção por códigos alfanuméricos.
- Teclado digital para inserir códigos.
- Validação de códigos e mensagens de erro.
- Animação de liberação do prêmio.
- Compartimento de retirada com acesso à playlist selecionada.
- Integração com o Spotify.
- Interface responsiva com identidade visual em azul-marinho, branco e prateado.

### 🛠️ Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript
- Spotify

### 🎯 Objetivo
Desenvolver uma experiência interativa que une tecnologia, música e criatividade, aplicando conceitos de desenvolvimento front-end, manipulação do DOM, eventos JavaScript e design responsivo.

**Projeto desenvolvido para fins educacionais e de portfólio.**
